How this works. An uploaded image is deskewed, the printed grid is separated from the stylus trace using the red channel, the grid period gives millimetres per pixel, and the trace is followed column by column to recover a calibrated signal. That signal is then measured — Pan-Tompkins QRS detection, RR statistics, QRS duration, atrial activity — and those measurements drive a transparent rule engine. When a trained convolutional model is present it reads the image independently and the two results are compared; disagreement is reported rather than hidden.

Reference strips are synthetic waveforms from ml/synth.py, not clinical recordings. Accuracy figures require PhysioNet data — see docs/METHODOLOGY.md.
